## Prerequisites

- **NodeJs** - Required to run the project. Download from [here](https://nodejs.org/en/download). 
- **Git** - Requiered to clone the repository. [here](https://git-scm.com). 



## Get Started

1. **Clone the repository**
```bash
   git clone https://github.com/FernandoJoachin/professional-readiness-sprint.git
   cd professional-readiness-sprint
```

2. **Install dependencies**
```bash
   npm install
```

3. **Build the project**
```bash
   npm start build
```

4. **Run the project**
```bash
   npm start dev
```
